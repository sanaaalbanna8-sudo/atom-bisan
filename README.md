# مكونات الذرة — عرض بيسان طارق

عرض ويب لمادة الكيمياء، الصف التاسع ب، درس **مكونات الذرة والنماذج الذرية**.

## التشغيل

افتحي ملف `index.html` في المتصفح، أو ارفعي المجلد كاملاً إلى GitHub ثم فعّلي GitHub Pages.

## التنقل

- القوائم أعلى كل صفحة
- أزرار التالي / السابق
- سهم اليسار = الصفحة التالية (العربية)
- سهم اليمين = الصفحة السابقة
- زر الصوت أسفل اليمين يفتح صوت المختبر
